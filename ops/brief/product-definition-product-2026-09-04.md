# What Delphinium IS (Product desk, 2026-09-04)

## IS (public-safe one sentence)
Delphinium is a Canvas LMS plugin that adds student engagement (gamification, progress, motivation) and staff tools (Control Tower + family messaging) inside the courses schools already run — without rebuilding content.

## IS NOT
- Not a website, landing page, or content hub
- Not a replacement for Canvas / SIS / ParentSquare
- Not “analytics that only detect at-risk” (Product: competitors detect/notify; we change what the student does — see public clash with Marketing SOURCE hard-no on that exact phrase)
- Not a course rebuild or rip-and-replace LMS

## Outcome
Davis: 31% failure-rate drop, 72 fully online classes / ~6,000 students, same courses/teachers/content; 72% more/much more motivating. Lead 31%; 72% for principals/culture.

## Friend-tell
“It’s the Canvas add-on that makes online kids actually want to do the work — schools saw failure rates drop about a third without changing the course.”

## Marketing language Product rejects
“It’s the site where…”; feature laundry before 31%; implying Delphinium is Canvas or replaces parent-comms; Control Tower as whole product; inventing stats / named quotes without Jared OK.
