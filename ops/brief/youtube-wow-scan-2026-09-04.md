## 4) Visual/tone cues to steal (not copy)
1. **Mint→teal gradient with an off-center white/soft UI card.** Their videos live on a pale mint-to-teal wash; a floating browser panel with a colored 3–4px border pops hard against it. Cheap, distinctive, non-corporate — good base for a quirky-but-cutting-edge site.
2. **Four-color CMY-ish accent system from the logo** (magenta / yellow / cyan-blue / green) used as *state* color, not decoration: green=good, yellow=watch, red=act, magenta=highlight. Site can inherit this so screenshots and UI never fight the page.
3. **Tone: "before they ask."** The strongest copy on the channel is short, human, slightly ominous-then-relieved — problem in 5 words, UI beat, relief. Pairs with real animated-detail moments (countdown rings, status stripe filling) rather than hero illustrations. Lean on annotated real UI + one-line human captions; skip stock-footage smiling-teacher imagery, which is where the older persona videos feel dated.
