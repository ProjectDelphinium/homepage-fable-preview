## Category (position)
Delphinium is a **Canvas LMS enhancement / plugin** — a layer that sits inside courses schools already run. Not an LMS, not a Canvas replacement, not a website, not admin analytics alone.

## For whom (homepage default)
Primary: **Director of Digital / Online Learning** (K-12 online / virtual / cyber).
Co-buyer: **Principal / head of virtual school**.
Gate: CTO / IT / Canvas admin (low risk, LTI, no rip-and-replace).
Higher Ed: secondary path (`/highered`), not homepage hero.

## Against what (competitive frame — internal)
Rarely a named rival. Real losses: budget / non-adoption / don’t-see-value / **do-nothing**.
Internal wedge (SOURCE): competitors detect or notify; Delphinium changes what the student does.
**Public:** do **not** use that wedge phrase unless Jared OKs; use demonstrable engagement + measured outcome instead.

## Position statement (homepage-safe draft)
Delphinium works with Canvas to turn engagement into action — identify who’s stuck, understand why, reach students and families, and give students a reason to stay engaged — with a measured outcome, without rebuilding the course.

Shorter: A Canvas layer that turns engagement into action, with a measured outcome.

## Value statements (SOURCE-safe, ranked for homepage)

1. **Outcome (DOL / board):** Same courses, same teachers, same content — course failure dropped **31%** across 72 fully online classes (~6,000 students).
2. **Motivation (principal / culture):** **72%** of students more / much more motivating; Tiffany Dance — students redoing quizzes for avatar points.
3. **Teacher load (operational):** Natalie Niederhauser — ~12 emails/day → ~6 messages/week.
4. **Canvas you already own (post-ESSER / IT):** Maximize Canvas; Canvas-native LTI; ~3-min setup; no rip-and-replace.
5. **Action from Canvas data (how, not hero):** See who’s not engaging and reach them (and families) from inside Canvas — paraphrase only on public pages.
