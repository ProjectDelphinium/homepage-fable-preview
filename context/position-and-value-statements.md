## 1) Position statements

### ★ Headline
**Canvas delivers content. Delphinium delivers engagement.**

Also approved: Do more, in less time · Transform Canvas into an engagement engine · Which class would YOU rather take? · Give Canvas a Makeover! · Student Success Made Simple.

### Category
Canvas LMS **engagement layer** / enhancement for **virtual and online K-12**. Turns an existing Canvas course into a visual, motivating student experience and an early-warning system for teachers in ~**3 minutes**. No migration. Teachers keep using Canvas — just turn it on.

### Positioning statement (canonical from pack)
For virtual and online K-12 schools running courses in Canvas, Delphinium is the Canvas engagement layer that turns an existing Canvas course into a visual, motivating experience for students and an early-warning system for teachers in about three minutes — unlike general LMS tools, which deliver content but don't address whether students want to engage with it.

### 25-word description
Delphinium turns the Canvas courses virtual schools already have into engaging experiences for students and early-warning systems for teachers — with no extra work for teachers. Just turn it on.

### Who for / vs what
**For:** Virtual/online/cyber K-12 (DOL, principal, teachers; IT gate).  
**Vs:** LMS tools that deliver content but don’t make students *want* to engage; gray wall of text; tools that only detect/notify without engagement + outreach.  
**Not:** An LMS, rip-and-replace, a website, admin-analytics-only, higher-ed-first homepage.

### Post-ESSER / multiplier
Maximize the Canvas (and teacher/content spend) you already own — lower failure means that spend isn’t wasted.

## 2) Value statements (ranked for homepage)

1. **★ Measured outcome:** Davis Connect study — 72 classes, 6,000 students, same courses/teachers/content → **31%** drop in course failures.
   - **Promises / forward-looking (homepage, ads, CTAs):** always **“up to 31%.”**
   - **Citing Davis study:** exact **31%** with study named + context.
   - (Jared locked 2026-09-04.)
2. **★ Motivation:** **72%** more/much more motivating; students’ most common word: **“Fun.”**
3. **★ Student behavior:** Redo quizzes for avatar points (Tiffany Dance); Netflix→homework student quote.
4. **★ Teacher time:** Natalie Niederhauser — ~12 emails/day → ~6 messages/week; Saturday nights back; message struggling group fast.
5. **3-minute Makeover:** Gray scroll of death → visual color-coded course (before/after is the first thing to show).
6. **Control Tower:** See who’s red/yellow/green; filter; message + CC parents in under a minute.
7. **Message Center:** Templates, relative dates, conditional send, multi-channel (Canvas + email + banner + to-do).
8. **Low risk:** ~3 min setup, no migration, no new teacher tool, Chromebook-friendly, aliases/FERPA-aware leaderboards.
9. **Family / parents (supporting):** informed parents, early calm outreach, positive school–family loop — after Makeover + Davis on homepage.

### Pain → value (homepage-ready)
| Pain | Value answer |
|---|---|
| Canvas is a gray wall of text | 3-minute Makeover |
| Students not logging in / async motivation | Gamification + nudges for the majority (progress/belonging) |
| Failure & withdrawal too high | Control Tower + Davis 31% |
| Parents can’t see how kid is doing | Color-coded parent view |
| Teachers buried in outreach | Message Center / automation |
